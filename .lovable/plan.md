# X Ads Banner Set - The Crypto Final Boss

## Ziel
Ein Set moderner Werbe-Banner für X Ads, in der bestehenden Optik (Gold / Neon-Grün / warmes Schwarz, Gorilla King, Cinema-Look). Branding immer exakt "The Crypto Final Boss", CTA auf Oktober-$TCFB-Launch bzw. "play free".

## Formate (X Ads Spezifikationen)
| Format | Größe | Einsatz |
| --- | --- | --- |
| Website Card / Image Ad | 1200 x 628 | Haupt-Ad-Format im Feed |
| Square Ad | 1200 x 1200 | Mobile Feed, hohe Sichtfläche |
| Header / Profil-Banner | 1500 x 500 | Profil-Kopf, Kampagnen-Look |
| Vertical Ad | 1080 x 1350 | Mobile-optimierte Variante |

## Varianten (je eigene Bildidee + Copy)
1. **Throne / Boss Flex** - gekrönter Gorilla vor Trading-Wall, Headline "survive 84 months of crypto", Sub "real prices 2020-2026".
2. **Liquidation** - roter Liquidations-Glow, Headline "97% get liquidated", Sub "are you the final boss?".
3. **Terminal Showcase** - Game-Terminal als Hero-Element mit Chart/Perps, Headline "trade. rug. rekt. repeat.".
4. **$TCFB Launch Teaser** - dunkles Gold-Setup, "October. $TCFB." als Fokus, Game-URL als Sub.

Jede Variante bekommt Headline, Sub, CTA-Button-Look und das Logo, klar lesbar auch als kleine Feed-Vorschau (große Typo, hoher Kontrast, kein Text im äußeren 5%-Rand).

## Ablage & Dokumentation
- Bilder: `x-assets/ads/` (z. B. `ad-throne-1200x628.jpg`, `ad-liquidation-1200x1200.jpg`, ...)
- Textbausteine (Headline, Beschreibung, CTA je Variante, X-Ads-tauglich) in `x-assets/x-ads-copy.md`.

## Technisches
- Bilder werden per Bildgenerierung erzeugt (premium-Tier wegen Text/Typografie), keine Änderungen am Game-Code.
- Keine Hashtags, Copy kurz und in der bekannten trockenen Voice, aber Ad-tauglich (klarer Nutzen + CTA).
